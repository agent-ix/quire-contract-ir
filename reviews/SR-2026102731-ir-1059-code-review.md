## Summary

Reviewed IR-1059 PR #672, including the production type resolver and public reader replay. The published intake rows are exercised, but a newly admitted native type cannot be resolved when used by a tuple or union.

## Verdict

**FAIL** — the reader admits a Duration tuple position or variant payload in step 1 while its operation-stage member type resolver always returns no type for Duration.

## Findings

| ID | Severity | Summary | Refs |

| FND-001 | high | Admitted Duration position and payload cannot resolve to the required Quantity<s> type | crates/quire-contract-model/src/checked_package/v2/model_members.rs:1414 |

## Review evidence

QSpec FR-322's step 4 table assigns native Duration the selected owner's resolved s unit type, Quantity<s>, subject to the stated unit checks. TK-25 and TK-26 explicitly admit Duration in tuple positions and variant payloads. This PR recognizes Duration in `NativeTypeRef`, and its intake loop admits it, but `DomainModel::element_type_leaf` returns `None` for Duration. `check_tuple_position` and `selected_union_members` use `element_type` and therefore cannot validate an otherwise valid projection or union value with that type. The replay tests only step 1 admission for TK-25/26 and remove expression nodes, so they do not reach either use.

The changed files do not alter CI workflows, dependencies, unsafe code, or a wire schema. Public enum additions are documented and exhaustive match sites inspected. Focused checks and formatting reported by the coder were not rerun during this review; hosted Rust Checks were in progress at review time. No full local build was run because the code lead owns the final aggregate gate.

## Fix round evidence

QSpec FR-322's Duration row says a missing source or selected `s` must refuse `missing_declaration`/`missing-name`. The new `element_type_leaf` returns `None` when `own_seconds_declared` is false and no source `s` exists, or when the selected document declares `s` but no matching graph unit exists. `check_tuple_position` uses `.and_then(|type_ref| owner.package.element_type(type_ref))` and routes that `None` through `ineligible()`, which yields `ill_typed`/`operator-ineligible`. This is reached after the selected-document intake admits Duration as TK-25 requires. The existing positive control covers only resolvable `s` cases. An invalid but present `s` legitimately takes the no-type/`ill_typed` branch; the absent unit needs the distinct missing-name result.
