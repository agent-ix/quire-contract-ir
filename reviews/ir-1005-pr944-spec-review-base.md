## Summary

Ticket: IR-1005. Reviewer-only spec-review/base pass over `git diff origin/main...HEAD` of quire-contract-ir PR #944 at 40ac6f940936280b84a5c88a2cef846f3c59aef2, against owner APIs at origin/main of quire-spec-language, quire-observation, quire-integration and quire-contract-model, and quire-mltl origin/main plus open PRs #17/#18. Sibling quire-integration #88 (IT-022) was read for contradictions only.

## Verdict

**FAIL** — three high and one medium finding. The TL request construction order is acyclic (the request carries the native subject name and the constant profile name, the record carries the request bytes); the RFC 8785/hex/decimal-string rule is well chosen; AC-7 was already withdrawn on origin/main under the no-hash rule and this PR only rewords it, so it is not a scope cut; no frozen digest, pin or vendored owner file is added. The owner APIs named largely exist at origin/main (QSL `ValuationEvidence`, `CheckedSubject::{new,with_predecessor}`, `Report::{from_owner_bytes,to_owner_bytes_bounded,validate_predecessor}`, `evaluate_v2`; checked_views `mapping_support`, `belongs_to`, `name_of`, `clock_of`, `requirements`, `predicate_leaves`, `formula_graph`; IR `lock`, `term`, `source_map`, `selected_model_packages`; quire-mltl `RequestInput` per #17 and `validate_supplied_predecessor` per #18). The defects below are places where a coder must still decide, or where the stated contract cannot be met against the owner.
