# FR-007: Classify components and artifacts

## Description

The governance contract shall classify every program crate and material emitted artifact exactly as specified by PGM-01-R07.

## Inputs

The eight repositories, emitted runtime/evidence artifacts, external engines, and actual deployment role.

## Outputs

A primary boundary class and any project-specific reassessment obligation.

## Behavior

- Classes are linked runtime, direct development tool, analysis/evidence tool, or external engine adapter.
- Actual deployment that differs from the primary class is declared and reassessed.

## Acceptance Criteria

| ID | Criteria | Verification |
|---|---|---|
| FR-007-AC-1 | The canonical table covers all eight repositories, generated runtime, reports, and external-engine adapters. | Inspection (TC-002) |
