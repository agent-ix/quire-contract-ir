## Summary

Reviewed the callable read on PR #762 head d4b0c53 against FR-354-AC-3, FR-352-AC-10, and repository Rust conventions. No applicable AssuranceProfile was found under `spec/`. The read can expose a nonexpression body and uses the wrong typed refusal for source anchors.

## Verdict

**FAIL** — two behavior defects remain.

## Findings

| ID | Severity | Summary | Refs |
| --- | --- | --- | --- |
| FND-001 | high | A body reference to any admitted term is accepted as an executable callable body; it need not target an expression node. | crates/quire-contract-model/src/checked_package/v2/callable.rs:174 |
| FND-002 | medium | A source-declared anchor without a selected model member returns `UnsupportedSelectedOperation` instead of the specified unavailable-witness outcome. | crates/quire-contract-model/src/checked_package/v2/callable.rs:353 |

## Coverage

- FR-354-AC-3, role: examined. Excerpt: Given a matching FR-352 `SelectedOperationMemberRow`, the callable projection returns each selected model-owned operation's ordered parameters, admitted body handle, context and frame, including an intentionally empty frame; a pure function can be read from its admitted node without that row. A missing or conflicting model-member row, a source-declared operation anchor without its own producer witness, a dangling body, wrong owner or absent required frame returns a typed outcome without a callable view.
- FR-352-AC-10, role: examined. Excerpt: A source-declared anchor with no selected model member returns typed unavailable-witness rather than accepting a same-name model-member row.
- FR-019 public callable inventory, role: context_only. Excerpt: types `CheckedCallable`, `CheckedCallableIdentity`, `CheckedCallableReadError`, `CheckedCallableReadErrorCode`, `CheckedCallableTable`; associated callable_table read.

## Evidence

`function_body` checks only `package.term(target).is_none()` for the body binding. The structural validator's `StructuralForm::of` maps function forms to `None`, so admission does not establish that the body target is an expression. A body reference to a retained scalar node therefore passes this read and exposes a wrong body handle. The source anchor branch is reached before the public witness read and emits `UnsupportedSelectedOperation`.
